# Roadmap

This roadmap is not a schedule or delivery-date commitment.

## v0.1 public foundation

- Open-source repository foundation.
- Installation and release workflow.
- Alpha compatibility validation.
- Further UI convergence.
- A basic static or lightweight mascot placeholder.

## v0.2 animation and themes

- A 2D mascot.
- Low-frame-rate PNG or sprite animation.
- Usage-driven mascot states.
- Lightweight themes and reduced-motion support.

## v0.3 community extension

- Asset-pack specification.
- Additional character styles.
- Community-feedback-driven improvements.
- Evaluation of other providers only when justified by real demand.

The first public version does not target macOS/Linux, a separate login system,
a project-operated cloud service, or a theme marketplace.
