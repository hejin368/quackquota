# QuackQuota roadmap

This roadmap is not a schedule or delivery-date commitment.

## v0.1 public foundation

- Installation and release workflow.
- Alpha compatibility validation.
- Further UI convergence.
- A basic static mascot placeholder only after a reviewable asset exists.

## v0.2 mascot and local personalization

- A low-frame-rate 2D duck using PNG frames or a sprite sheet.
- Usage-driven mascot states and reduced-motion support.
- A local-only duck name (`duckName`) after a mascot UI exists. It will not be
  tied to an account, uploaded, synchronized, or used for telemetry.

## v0.3 community extension

- Asset-pack specification and additional visual styles.
- Community-feedback-driven improvements.
- Evaluation of other providers only when justified by real demand.

The first public version does not target macOS/Linux, a separate login system,
a project-operated cloud service, or a theme marketplace.
